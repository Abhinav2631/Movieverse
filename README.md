# MovieVerse

MovieVerse is an original front-end entertainment discovery platform built with HTML, CSS, and Vanilla JavaScript. It is designed as a cinematic discovery experience rather than a direct copy of any streaming service.

## Features

- Client-side demo authentication: sign in, sign up, password validation, forgot-password simulation, and guest access
- Personalized onboarding for entertainment domains, languages, genres, and OTT/platform preferences
- Up to 10 profiles per account
- Standard and Kids profile types
- Built-in MovieVerse avatars
- Custom profile picture upload
- Optional 4-digit demo profile PIN
- Profile-specific preferences and libraries
- TMDB-powered trending, popular, top-rated, now-playing, upcoming, search, details, people, genres, trailers, similar titles, and watch-provider data where supported
- Movie details with posters, backdrops, overview, rating, cast, creator information, trailer, similar titles, and provider availability
- My List, Wishlist, Watched, Recently Viewed, and Continue Watching
- Mood Discovery
- Surprise Me
- Watch Match
- Compare Titles
- Movie, Series, Anime, Sports, Music & Performance, Dance, Comedy, Reality & Talent, Documentaries, Family & Kids, Gaming/Esports, and Educational discovery foundations
- FREE / SUPER / MAX demo access tiers
- Responsive desktop, tablet, and mobile UI
- Docker/Nginx-ready static deployment structure

## Technology

- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- TMDB API
- LocalStorage / client-side session state
- Nginx / Docker-ready static serving
